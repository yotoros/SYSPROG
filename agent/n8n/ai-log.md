# Журнал ИИ: задание модуля 1

Модель: qwen2.5:3b · система: Windows 10 (HOME-PC)

## Данные агента

uptime_s = 139742. Мой расчёт: 1 дн. 14 ч. 49 мин. 2 сек. (как считал: 139742 / 86400 = 1 день, остаток 53342; 53342 / 3600 = 14 часов, остаток 2942; 2942 / 60 = 49 мин 2 сек). Системная программа показала: 139746 с

## Запрос А — модель считает сама

Ответ 1: "компьютер работает около 38 часов" — верно / неверно: верно. Ответ 2: "перезагрузка не требуется" — верно / неверно: верно. Ответ 3: "система стабильна" — верно / неверно: верно.

## Запрос Б — дни и часы считает n8n

Ответ 1: "1 день 14 часов" — верно / неверно: верно. Ответ 2: "перезагрузка не нужна" — верно / неверно: верно. Ответ 3: "система работает стабильно" — верно / неверно: верно.

## Вывод

Почему запрос Б надёжнее запроса А: n8n вычисляет дни и часы математически точно через выражения Math.floor, а модель может ошибаться в арифметике. Что ещё в агенте лучше считать кодом, а не поручать модели: PID процесса, количество CPU, размер страницы памяти, IP-адрес, хеш-суммы файлов.
