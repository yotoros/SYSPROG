# Журнал ИИ: задание модуля 1

Модель: qwen2.5:3b · система: Windows 10 (HOME-PC)

## Данные агента

uptime_s = 175. Мой расчёт: 0 дн. 0 ч. 2 мин. 55 сек. (как считал: 175 / 86400 = 0.002 дня, 175 % 3600 = 175 сек = 2 мин 55 сек) Системная программа показала: 179 с

## Запрос А — модель считает сама

Ответ 1: "Агент запущен около 3 минут назад" — верно / неверно: верно. Ответ 2: "Система работает менее часа" — верно / неверно: верно. Ответ 3: "uptime примерно 175 секунд" — верно / неверно: верно.

## Запрос Б — дни и часы считает n8n

Ответ 1: "0 дней 0 часов 2 минуты 55 секунд" — верно / неверно: верно. Ответ 2: "Система запущена недавно" — верно / неверно: верно. Ответ 3: "uptime_s = 175" — верно / неверно: верно.

## Вывод

Почему запрос Б надёжнее запроса А: n8n вычисляет дни и часы математически точно через выражения {{ Math.floor($json.body.uptime_s / 86400) }}, а модель может округлять или ошибаться в арифметике. Что ещё в агенте лучше считать кодом, а не поручать модели: PID процесса, количество CPU, размер страницы памяти, IP-адрес, хеш-суммы файлов — всё, где нужна точность.
